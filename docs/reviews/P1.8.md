### Findings

No P1 or P2 findings.

- **P3 - README "Other hosts" overstates where the core runs.** `README.md`, section Other hosts:
  "The core runs anywhere there is a `document`" and `import "@edgesweden/consent/styles.css"; //
or <link rel="stylesheet">`. `dist/index.js` begins with `import'./styles.css'` (decision #7,
  plan: No visual flash), so the entry needs a bundler that handles CSS imports; loaded as native
  ESM (import map, no bundler) the module fails with a MIME-type error, and the explicit
  stylesheet import is redundant under a bundler. Suggest: say a CSS-aware bundler is required and
  drop the separate stylesheet line, or note that it is only needed when the bundler drops
  side-effect CSS imports.
- **P3 - README Records: cookie wording for a cross-origin URL.** "same-origin cookies" is accurate
  for a root-relative URL; for an absolute cross-origin URL `sendBeacon` sends with credentials, so
  the endpoint origin's own cookies (subject to `SameSite`) are attached. Suggest "the cookies the
  browser holds for the endpoint's origin".
- **P3 - README Accessibility: Escape in the settings dialog.** "returns to the banner if the
  banner opened it" - `closeSettings` in `src/core/banner.ts` returns to the banner whenever no
  valid choice exists yet, regardless of opener. Suggest "returns to the banner while no choice
  has been made".
