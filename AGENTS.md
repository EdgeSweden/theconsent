# Contributor and agent instructions

[`docs/plan.md`](docs/plan.md) is this repository's product contract and operating contract. Read
it before changing anything: its Delivery section defines how a package is implemented, reviewed
and handed to a maintainer, and its Checks section defines the gate (`pnpm check`) every change
must pass. Git is read-only for implementers and agents; maintainers commit, merge, push and tag.
